# Jolt extras

Optional and advanced features. The core API is in llms.txt. One compact line per feature, grouped by area.

## Protocol
Expect: 100-continue is answered before the body is read; declared length over maxBodyBytes gives 413 unread, other Expect values 417.
JSON binds Instant, LocalDate/Time, LocalDateTime, Offset/ZonedDateTime, Duration (ISO), UUID, BigDecimal, enums (by name) and Optional (empty: omitted in records, null in Map/List); bad values give 400.
req.parts() reads multipart/form-data in memory: Part name(), filename() (sanitised, null for fields), contentType(), bytes(), text(). Limits maxParts(10), maxPartBytes(1 MB), maxBodyBytes: 413; malformed 400; other types 415.
config.trustProxy("10.0.0.0/8", "::1") (default none): only those peers get X-Forwarded-For (rightmost untrusted), -Proto, -Host applied to req.remoteAddress(), req.scheme(), req.host(); RateLimit.perIp then keys on the client.

## Response
    app.views(Path.of("views"), "layout")  res.render("page", Map.of("u", user))   // page.html: {{x}} escaped, {{{x}}} raw, a.b, {{#each xs}}{{.}}{{/each}}, {{#if x}}, {{> part}}; layout prints {{{content}}}; names confined to root, mtime-cached
    app.codec(new CsvCodec())  res.send(obj)   // BodyCodec{mediaType,read,write}: req.body(T) by Content-Type, res.send by Accept (JSON default); 415 unknown type once a codec exists, 406 no match
    app.use(Static.serve("/", dir).spaFallback("index.html"))   // MIME map, index.html (dir gets 301 to /), single Range + If-Range (206/416), 304; SPA fallback opt-in, only for unrouted browser navigations (Accept text/html, no dot)
    res.json(x).etag()  res.cache(Duration.ofMinutes(5))  res.noStore()   // weak ETag + 304 on If-None-Match; max-age; no-store. sendFile/Static do 304 (ETag, Last-Modified) automatically
    app.use(Compress.gzip())              // opt-in; gzip(minBytes), default 1024; honours Accept-Encoding q=0, sets Vary; skips images/zip/encoded; BREACH: not for pages mixing secrets with user text

## Routing
Path patterns: /users/:id(\d+) (regex, full match; a miss falls through to the next route, then 404), /files/:name? (optional last param). Order: static, constrained, plain, wildcard. Bad regex, duplicate names or /files/:name? next to /files: IllegalArgumentException at registration.

## Security
app.use(Sessions.signed(secret32+)) keeps a Session in an HMAC-SHA256 cookie (signed, not encrypted): Sessions.of(req).get/put/remove/clear/isNew; values String, finite number, boolean; 3 KB cap throws IllegalStateException; .maxAge(1h, renewed at half) .previous(oldKeys) .cookie(name); HttpOnly, SameSite=Lax, Secure per config; cookie set only on change.
app.use(Csrf.protect()): POST/PUT/PATCH/DELETE with cookies need Sec-Fetch-Site same-origin|same-site|none, else Origin/Referer matching Host, else 403; cookieless API calls skip unless .strict(); .token(secret32) adds a signed double-submit token (csrf cookie == X-CSRF-Token header or _csrf form/multipart field; only same-origin|none; .token() unsigned is weaker); Csrf.token(req) for forms.

## Auth
RefreshTokens.of(jwt) (.accessTtl 15m, .refreshTtl 30d, .store(RefreshStore), .claims(subject->map), .onRevoke((subject,family)->..)): issue(subject), refresh(token) rotates (opaque 256-bit token, SHA-256 hash stored); reuse revokes the family (rotation is atomic in the store); failures throw HttpException 401, a full store 503 (20 live tokens per subject, 10000 total); revoke(token), revokeAll(subject).

## Observability
app.use(RequestId.middleware()): X-Request-Id kept if [A-Za-z0-9._-]{1,64}, else a random 16-hex id; req.id() (null without it), echoed on the response and appended to Logger.requests() lines.

## Dev and tooling
jolt-dev (dev only, dep jolt-dev): class DevMain{main(){Dev.run("app.Main",Path.of("target/classes"));}}; run mvn -q compile exec:exec -Dexec.executable=java "-Dexec.args=-cp %classpath app.DevMain" (not exec:java), recompile to restart; child gets JOLT_DEV=1; app.use(DevErrors.page(app)) first renders non-HttpException, unmapped errors as HTML only when JOLT_DEV or -Djolt.dev=true.
mvn archetype:generate -DarchetypeGroupId=com.github.THIRU-1074.custom-Http-Server -DarchetypeArtifactId=jolt-archetype -DarchetypeVersion=<tag> -DarchetypeRepository=https://jitpack.io scaffolds a Jolt app (pom with jolt.version, Main, JoltTest test, llms.txt, AGENTS.md).

## Modules
jolt-db (in.jolt:jolt-db, JDK java.sql only): Db db=Db.open(jdbcUrl[,size=8,timeout=5s]).queryTimeout(30s default); db.query(sql,rs->..,args..)->List; queryOne->Optional; update->rows; db.inTransaction(tx->{tx.update(..);return x;}) rolls back on any throwable; ? params only; close() the pool.
