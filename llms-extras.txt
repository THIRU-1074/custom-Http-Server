# Jolt extras

Optional and advanced features. The core API is in llms.txt. One compact line per feature, grouped by area.

## Protocol
Expect: 100-continue is answered before the body is read; declared length over maxBodyBytes gives 413 unread, other Expect values 417.
JSON binds Instant, LocalDate/Time, LocalDateTime, Offset/ZonedDateTime, Duration (ISO), UUID, BigDecimal, enums (by name) and Optional (empty: omitted in records, null in Map/List); bad values give 400.
req.parts() reads multipart/form-data in memory: Part name(), filename() (sanitised, null for fields), contentType(), bytes(), text(). Limits maxParts(10), maxPartBytes(1 MB), maxBodyBytes: 413; malformed 400; other types 415.
config.trustProxy("10.0.0.0/8", "::1") (default none): only those peers get X-Forwarded-For (rightmost untrusted), -Proto, -Host applied to req.remoteAddress(), req.scheme(), req.host(); RateLimit.perIp then keys on the client.
config.tls(keystorePath, password) or tls(SSLContext) serves HTTPS (TLS 1.2+, forward-secret AEAD suites; req.scheme() is "https", usable in SecurityHeaders.hsts); plain HTTP stays default; a reverse proxy is still the usual production route.
res.sse() (event(name, data), comment, retry; text/event-stream, unbuffered) and res.stream() (write(String|byte[]), close; chunked) run on the connection thread and end it when the handler returns; a gone client throws IOException, a handler failure truncates the body; HEAD discards, HTTP/1.0 is close-delimited; config.streamTimeouts(idle 60 s, max 1 h; 0 = no cap) closes stalled streams.
app.ws(path, handler).origins("https://a.example") serves WebSocket (RFC 6455) on the connection thread; WebSocketHandler onOpen/onText/onBinary/onClose or WebSocketHandler.text((s, m) -> s.send(m)); session send(String|byte[]), ping(), close(code, reason). Middleware runs before the upgrade. Origin must match Host unless listed; config.wsLimits(64 KB frame, 1 MB message) closes 1009; idle: ping after streamTimeouts idle, drop after 2x, max caps total.

## Response
    app.views(Path.of("views"), "layout")  res.render("page", Map.of("u", user))   // page.html: {{x}} escaped, {{{x}}} raw, a.b, {{#each xs}}{{.}}{{/each}}, {{#if x}}, {{> part}}; layout prints {{{content}}}; names confined to root, mtime-cached
    app.codec(new CsvCodec())  res.send(obj)   // BodyCodec{mediaType,read,write}: req.body(T) by Content-Type, res.send by Accept (JSON default); 415 unknown type once a codec exists, 406 no match
    app.use(Static.serve("/", dir).spaFallback("index.html"))   // MIME map, index.html (dir gets 301 to /), single Range + If-Range (206/416), 304; SPA fallback opt-in, only for unrouted browser navigations (Accept text/html, no dot)
    app.use(Static.classpath("/", "/static"))  app.viewsClasspath("/views", "layout")   // jar or target/classes, context loader (or pass a ClassLoader); same rules as serve/views; jar ETag from size+CRC; templates read once
    res.json(x).etag()  res.cache(Duration.ofMinutes(5))  res.noStore()   // weak ETag + 304 on If-None-Match; max-age; no-store. sendFile/Static do 304 (ETag, Last-Modified) automatically
    app.use(Compress.gzip())              // opt-in; gzip(minBytes), default 1024; honours Accept-Encoding q=0, sets Vary; skips images/zip/encoded; BREACH: not for pages mixing secrets with user text

## Routing
Path patterns: /users/:id(\d+) (regex, full match; a miss falls through to the next route, then 404), /files/:name? (optional last param). Order: static, constrained, plain, wildcard. Bad regex, duplicate names or /files/:name? next to /files: IllegalArgumentException at registration.
Page p=Page.of(req|params) reads ?page (1) &size (20, capped 100; of(req,def,max)); bad or <1 is 400; p.offset() p.limit(); p.result(items,total) is JSON {items,page,size,total,totalPages}; .link(req,res) sets Link first/prev/next/last keeping other query params.
Nested rules: r.nested("customer", b.customer(), (c, cr) -> cr.notBlank("email", c.email())) keys customer.email; r.each("seats", b.seats(), SEAT) runs a Validator per element, keys seats[2].row; they nest (order.items[1].sku); null value or element is "is required"; all in one 422.

## Request
req.queryAll("genre") returns every value in order (empty list if absent); queryAll("id", Long.class) converts like query(name, Class), 400 naming the parameter; query(name) stays the first value; also on Params.

## Lifecycle
app.onStart(Runnable) runs before listen binds the port (a throw aborts listen with IllegalStateException and runs the stop hooks); app.onStop(Runnable) runs on Server.close() and the closeOnShutdown hook after in-flight requests drain, once, in reverse order, each failure logged and skipped; app.lifecycle(start, stop) pairs them (stop runs after a failed start only if its start completed). Register before listen, else IllegalStateException.
app.every([name,] Duration, Runnable) repeats and app.after([name,] Duration, Runnable) runs once, each on a virtual thread from listen until Server.close() (interrupted, joined); a throw is logged and the schedule continues, a tick while the previous run is still going is skipped; first run after one period; exposeMetrics() adds jolt_task_runs_total, _failures_total, _skipped_total{task=name} (default name task-N; names [A-Za-z0-9_.:-]{1,64}, unique); register before listen.
Config.load() reads env and application.properties (classpath, then working dir) plus application-<profile>.properties (JOLT_PROFILE or -Djolt.profile); env wins, key db.url is read as db.url or DB_URL. string/integer/duration(500ms,30s,5m,2h,1d,PT30S)/bool(key) are required, (key,default) optional; missing or malformed throws ConfigException naming the key, never the value. toString() masks keys with secret, password or token.

## Security
app.use(Sessions.signed(secret32+)) keeps a Session in an HMAC-SHA256 cookie (signed, not encrypted): Sessions.of(req).get/put/remove/clear/isNew; values String, finite number, boolean; 3 KB cap throws IllegalStateException; .maxAge(1h, renewed at half) .previous(oldKeys) .cookie(name); HttpOnly, SameSite=Lax, Secure per config; cookie set only on change.
app.use(Csrf.protect()): POST/PUT/PATCH/DELETE with cookies need Sec-Fetch-Site same-origin|same-site|none, else Origin/Referer matching Host, else 403; cookieless API calls skip unless .strict(); .token(secret32) adds a signed double-submit token (csrf cookie == X-CSRF-Token header or _csrf form/multipart field; only same-origin|none; .token() unsigned is weaker); Csrf.token(req) for forms.
app.use(Idempotency.keys()) after auth: POST/PUT/PATCH with Idempotency-Key (1-128 printable ASCII, else 400) run once; a repeat replays status, headers (not Set-Cookie/Date/length) and body with Idempotency-Replayed: true; same key, other method/path/query/type/body 422; still running 409 + Retry-After; not stored: 5xx, 401/403/407/408/425/429, throws, streams, bodies over .maxBodyBytes(1 MB); scope = user attr (text/number), else hash of Authorization, else address, none 400, .scope(req->id); .required() .ttl(24h) .inFlightTimeout(5m) .methods(..) .store(IdempotencyStore: atomic begin/complete/release; default 10000 entries, 1000 per scope, store full of running 503).
app.use(Webhooks.hmacSha256(secret32+, "X-Signature")) verifies hex or base64 HMAC-SHA256 of the raw body in constant time, else 401 (generic); body still readable by the handler; .prefix("v1=") .timestampHeader("X-Timestamp") signs timestamp+"."+body and rejects unix-seconds stamps beyond .tolerance(5m) either way; .clock(c).

## Auth
RefreshTokens.of(jwt) (.accessTtl 15m, .refreshTtl 30d, .store(RefreshStore), .claims(subject->map), .onRevoke((subject,family)->..)): issue(subject), refresh(token) rotates (opaque 256-bit token, SHA-256 hash stored); reuse revokes the family (rotation is atomic in the store); failures throw HttpException 401, a full store 503 (20 live tokens per subject, 10000 total); revoke(token), revokeAll(subject).

## Observability
app.exposeMetrics() (opt-in, idempotent) serves GET /_jolt/health ({"status":"UP"}) and /_jolt/metrics (Prometheus text: requests by method and status class, final status after error mappers, latency histogram without streams, connections, streams, WebSocket gauges, body bytes; no paths or details); exposeMetrics(guard) protects /_jolt/metrics with a Middleware.
app.metrics().counter(name, help[, labelMap]) -> Counter(increment, add(n>=0), value) and .gauge(name, help[, labelMap], LongSupplier) add series after Jolt's own (names [a-zA-Z_:][a-zA-Z0-9_:]*, not jolt_*; duplicate name+labels or counter/gauge clash IllegalStateException; a throwing gauge is skipped); register before or after exposeMetrics/listen. app.health(name, Supplier<Boolean>[, Duration 2s]) adds checks to /_jolt/health: all true 200 {"status":"UP","checks":{..}}, else 503 with DOWN (false, null, throw, timeout; no error details); no checks keeps {"status":"UP"}.
app.use(RequestId.middleware()): X-Request-Id kept if [A-Za-z0-9._-]{1,64}, else a random 16-hex id; req.id() (null without it), echoed on the response and appended to Logger.requests() lines.

## Dev and tooling
JoltTest captures res.sse()/res.stream() in memory: result.events() (List<JoltTest.Event(name,data,id)>), text()/bytes() hold the streamed body; call.maxEvents(n) makes the nth+1 write throw IOException, call.timeout(Duration) drops the stream and interrupts a blocked handler; a throw after streaming began leaves status and output and shows in result.streamError(); WebSocket stays 501.
SSE resume: s.event(id,name,data) writes id: (null ok; CR/LF/NUL id -> IllegalArgumentException); req.lastEventId() = Last-Event-ID header or null; result.events() shows ids.
jolt-dev (dev only, dep jolt-dev): class DevMain{main(){Dev.run("app.Main",Path.of("target/classes"));}}; run mvn -q compile exec:exec -Dexec.executable=java "-Dexec.args=-cp %classpath app.DevMain" (not exec:java), recompile to restart; child gets JOLT_DEV=1; app.use(DevErrors.page(app)) first renders non-HttpException, unmapped errors as HTML only when JOLT_DEV or -Djolt.dev=true.
mvn archetype:generate -DarchetypeGroupId=com.github.THIRU-1074.custom-Http-Server -DarchetypeArtifactId=jolt-archetype -DarchetypeVersion=<tag> -DarchetypeRepository=https://jitpack.io scaffolds a Jolt app (pom with jolt.version, Main, JoltTest test, llms.txt, AGENTS.md).

## Modules
jolt-db (in.jolt:jolt-db, JDK java.sql only): Db db=Db.open(jdbcUrl[,size=8,timeout=5s]).queryTimeout(30s).busyTimeout(5s); query(sql,rs->..,args..)->List; queryOne->Optional; update->rows; insert->Optional<Long> key (empty if none inserted); batch(sql,List<Object[]>[,chunk=500])->int[] in one tx; inTransaction([TxMode.IMMEDIATE,]tx->{..;return x;}) rolls back on any throwable, tx unusable after; updateExpecting(sql,rows,args..) rolls back and throws OptimisticLockException (a DbException) on another count; IMMEDIATE = SQLite BEGIN IMMEDIATE, waits busyTimeout then DbException (other DBs: default mode); ? params only; close().
Migrations.run(db,Path[,lockTimeout=30s])/runClasspath(db,"db/migrations"[,..]) apply V<n>__<name>.sql by number, one tx each, in jolt_schema_history (success flag, SHA-256 of LF text); returns applied; a changed, duplicate or out-of-order file or an earlier failed (success=false) row throws DbException; concurrent starts wait and apply once; ;-separated plain SQL (no ? binding; quotes, $$, comments kept; no backslash escapes), triggers need a line `-- jolt:delimiter //`.
