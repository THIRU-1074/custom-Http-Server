## Dev and tooling
jolt-dev (dev only): Dev.run("app.Main",Path.of("src"),Path.of("target/classes")) restarts a child JVM on file change (env JOLT_DEV=1); app.use(DevErrors.page()) first renders exception+stack as HTML, install only in dev.

## Modules
jolt-db (in.jolt:jolt-db, JDK java.sql only): Db db=Db.open(jdbcUrl[,size=8,timeout=5s]); db.query(sql,rs->..,args..)->List; queryOne->Optional; update->rows; db.inTransaction(tx->{tx.update(..);return x;}) rolls back on throw; ? params only; close() the pool.
